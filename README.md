# ScopeBlind Homebrew Tap

```sh
brew install scopeblind/tap/protect-mcp
```

[protect-mcp](https://github.com/scopeblind/scopeblind-gateway) is a fail-closed Cedar policy gate with Ed25519-signed receipts for AI agent tool calls. It denies on any policy evaluation error and proves the gate is live with a boot self-test.
